# Cielo di Punta Falcone

Mappa del cielo interattiva dell'Associazione Astrofili Piombino: le foto dell'archivio dei soci messe nel cielo dove stanno davvero, viste dall'osservatorio di Punta Falcone.

## Apri la mappa

### 👉 **https://jacklions05.github.io/cielo-punta-falcone/**

Si apre nel browser, anche da telefono, senza scaricare niente.

- [`…/#timeline`](https://jacklions05.github.io/cielo-punta-falcone/#timeline) apre la timeline dell'archivio
- [`…/#visita`](https://jacklions05.github.io/cielo-punta-falcone/#visita) apre la prenotazione di una visita all'osservatorio
- `#` seguito dal nome di un oggetto, per esempio [`…/#M42`](https://jacklions05.github.io/cielo-punta-falcone/#M42), apre la mappa centrata su quell'oggetto
